# Planet imagery

Earth day, night, cloud maps and Moon albedo: Solar System Scope / INOVE,
https://www.solarsystemscope.com/textures/
Licensed under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Source images (8K) are based on NASA imagery. The website uses resized 4096×2048
and 2048×1024 WebP copies. Sources:

- https://www.solarsystemscope.com/textures/download/8k_earth_daymap.jpg
- https://www.solarsystemscope.com/textures/download/8k_earth_nightmap.jpg
- https://www.solarsystemscope.com/textures/download/8k_earth_clouds.jpg
- https://www.solarsystemscope.com/textures/download/8k_moon.jpg

The 1200×1200 posters are pre-rendered from the same website 3D scenes.
Moon relief is an aesthetic bump approximation from albedo, not an elevation survey.
No generated geographical details are used. No NASA or INOVE endorsement is implied.
